# 前言
一年四季仰望看到的形态各异的云朵们，感谢它们的存在让我知道这个世界有这么地大这么地美好。在分类过往看到的云的过程中（Reference: 云彩收集者手册，国际云图集），我也发现还有很多云不起眼但也值得收集，有很多云奇妙却转瞬即逝，还有些云只在特定的经纬度和极端的天气条件下才会出现，需要一辈子的时间才能幸运地碰上那么一两次。我会继续仰望天空，继续记录和收集看到的各式各样的云彩的。同时因为我不是专业气象学家，辨别云朵类型依靠的只有图鉴和Claude，所以这个网页里可能会有一些错误的分类。如果你看到了可以联系进行指正，我会修改。
